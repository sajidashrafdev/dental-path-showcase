---

# CLIENT OBJECTIVE

Completely refresh the existing Advanced Dental Assisting website.

The website must feel like a:

"Professional Dental Assisting Education & Training Program"

It should NOT feel like:

* A generic dental clinic
* A basic informational website
* A generic SaaS landing page
* A cheap template

The primary audience is prospective students.

The website should quickly explain:

1. What Advanced Dental Assisting is
2. What students will learn
3. Course structure and schedule
4. Program benefits
5. How to express interest/apply
6. Who the instructors are
7. How to contact the program

The website must be designed around converting visitors into prospective students.

---

# DESIGN STYLE

Create a premium modern dental education aesthetic.

Design characteristics:

* Clean
* Professional
* Trustworthy
* Modern
* Educational
* Welcoming
* Healthcare-inspired
* Premium but approachable
* Strong whitespace
* Excellent typography
* Strong visual hierarchy
* High-quality photography
* Conversion-focused CTA sections

Use a sophisticated dental/healthcare color palette.

Prefer:

* White / off-white backgrounds
* Deep navy or dark professional blue
* Teal / dental green accent
* Very subtle light blue/green backgrounds

Avoid:

* Purple
* Neon colors
* Excessive gradients
* Extremely rounded cards
* Generic SaaS aesthetics
* Excessive shadows
* Overly complicated layouts

Use subtle rounded corners only where appropriate.
