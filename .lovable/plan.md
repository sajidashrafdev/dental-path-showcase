# Advanced Dental Assisting Website Mockup

## Scope
Build a polished, responsive six-page frontend prototype with no database, authentication, CMS, or backend processing.

## Pages
- Home
- About the Program
- Course Information
- Meet the Team
- Interest / Apply
- Contact

## Implementation
- Create a shared sticky header, mobile menu, footer, button styles, section headings, content cards, team profiles, image/text layouts, forms, and conversion banners.
- Establish a premium dental-education design system using off-white surfaces, deep navy, teal accents, restrained corners, strong editorial typography, and subtle motion.
- Reuse verified first-party photos and copy from AdvancedDentalAssisting.com wherever accessible. Keep missing bios, schedules, and other unverified details as clearly editable placeholders.
- Build working internal navigation, clickable phone/email links, and placeholder Instagram links.
- Implement frontend-only interest and contact forms with validation-friendly controls and an in-page success state; no information will be stored or sent.
- Add route-specific page titles and social metadata for all six pages.

## Content and Experience
- Keep “I’m Interested” as the primary action throughout the journey.
- Structure the home page around program clarity, learning topics, benefits, instructors, next steps, and contact.
- Present course and team information without inventing dates, fees, credentials, accreditation, outcomes, or biographies.
- Use responsive desktop, tablet, and mobile compositions with a compact-on-scroll header and accessible mobile navigation.

## Verification
- Check every page and navigation path in desktop and mobile viewport sizes.
- Test mobile menu, forms, success states, phone/email actions, layout overflow, images, and animation behavior.
