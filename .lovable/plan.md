# Foods Valley Careers Page

## Goal
Replace the current dental education site experience with a polished, single-page careers site for Foods Valley Trading Co., focused on professional candidates in Saudi Arabia.

## Build
- Create a sticky corporate header with Foods Valley branding and direct links to openings, culture, and the application form.
- Build a full-width food distribution hero with the supplied headline, supporting copy, and a “View Open Positions” action.
- Add four culture and benefits highlights using restrained navy, white, green, and gold styling.
- Present the four supplied roles in a clear, filterable jobs section, with each “Apply Now” action preselecting the role and scrolling to the application form.
- Add a “Life at Foods Valley” values section focused on integrity, teamwork, food safety, and customer satisfaction.
- Build a frontend-only application form with name, email, phone, role, CV upload, cover letter, client-side validation, file restrictions, and a confirmation state.
- Replace the shared site header/footer and global branding with Foods Valley contact information and metadata.
- Use original, non-identifying food distribution imagery generated for the page.

## Technical details
- Keep the existing TanStack Start and Tailwind design system architecture.
- Use semantic color tokens and existing form/button components.
- Keep submissions entirely in the browser; no files or personal information will be stored or sent.
- Preserve the current extra URLs but make the requested Careers experience the primary `/` page.
- Verify desktop and mobile layouts, job selection, file validation, and submission behavior in the live preview.
